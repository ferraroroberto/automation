# Wi-Fi BAT Generator

GUI for picking a saved Wi-Fi network and saving a self-contained `.bat` file
that re-creates the connection on demand. The BAT carries the full WLAN
profile (SSID, password, security type) base64-embedded inside it, so it
works on any Windows PC without needing the profile to be already saved.

## How it works

1. Reads the currently-connected SSID from `netsh wlan show interfaces`.
2. Reuses `wifi_passwords.export_profiles` and `wifi_passwords.parse_profile_xmls`
   to enumerate every saved profile with its cleartext password.
3. Builds a `<WLANProfile>` XML matching the schema used by `wifi_connect.xml`.
4. Base64-encodes the XML, wraps it in a BAT that:
   - Skips connect if the target SSID is already active (idempotent).
   - Otherwise: writes the base64 to a temp file, runs `certutil -decode`
     to recover the XML, calls `netsh wlan add profile`, then
     `netsh wlan connect`, and cleans up both temp files at the end.

Why base64 over inline `echo` lines: cmd.exe `echo` requires escaping for
`< > & ^ | ( )`, and arbitrary SSIDs/passwords can contain any of those.
Base64 is `A–Z a–z 0–9 + / =` only, completely batch-safe with no escaping.
`certutil` ships with every supported Windows.

## Run

```powershell
& .\.venv\Scripts\python.exe system\wifi\wifi_bat_generator.py
```

The window shows the active SSID at the top and a sortable list of saved
profiles. Pick one and:

- **Save BAT…** opens a file dialog (default name `connect_<sanitized_ssid>.bat`).
- **Test selected** writes the BAT to `%TEMP%` and launches it in a new
  console window so you can watch it run.
- **Refresh** re-reads the current SSID and saved profiles.

Double-clicking a row is the same as **Save BAT…**.

## Generated BAT structure

```bat
@echo off
REM Generated by wifi_bat_generator.py - self-contained Wi-Fi connector.
REM Target SSID: REDWIFI_dGYG
setlocal
set "TARGET_SSID=REDWIFI_dGYG"
set "PROFILE_XML=%TEMP%\wifi_REDWIFI_dGYG.xml"
set "PROFILE_B64=%TEMP%\wifi_REDWIFI_dGYG.b64"

REM --- Skip if already connected to the target SSID ---
set "CUR="
for /f "tokens=2 delims=:" %%a in ('netsh wlan show interfaces ^| findstr /C:"SSID" ^| findstr /V "BSSID"') do set "CUR=%%a"
if defined CUR set "CUR=%CUR:~1%"
if /I "%CUR%"=="%TARGET_SSID%" (
    echo Already connected to %TARGET_SSID%.
    goto :end
)

REM --- Write base64 payload, decode to XML, add profile, connect ---
> "%PROFILE_B64%" (
    echo PD94bWwgdmVyc2lvbj0iMS4wIj8+CjxXTEFOUHJvZmlsZSB4bWxucz0iaHR0cDovL3d3dy5taWNy
    echo b3NvZnQuY29tL25ldHdvcmtpbmcvV0xBTi9wcm9maWxlL3YxIj4KICA8bmFtZT5SRURXSUZJX2RH
    REM ... more base64 lines ...
)
certutil -f -decode "%PROFILE_B64%" "%PROFILE_XML%" >nul
if errorlevel 1 ( echo Failed to decode profile. & goto :cleanup )

netsh wlan add profile filename="%PROFILE_XML%" user=current
if errorlevel 1 ( echo Failed to add Wi-Fi profile. & goto :cleanup )

netsh wlan connect name="%TARGET_SSID%"
if errorlevel 1 ( echo Failed to connect to %TARGET_SSID%. & goto :cleanup )

echo Connected to %TARGET_SSID%.

:cleanup
del /q "%PROFILE_B64%" "%PROFILE_XML%" 2>nul
:end
endlocal
pause
```

The `:cleanup` block runs on both success and failure (label fall-through),
so the temp files are removed in every case.

## Limitations

- Windows only — relies on `netsh` and `certutil`.
- Picker shows currently-connected + saved profiles only; not visible
  in-range networks. To create a BAT for a network you've never connected
  to, connect to it once first so it becomes a saved profile.
- The base64 payload contains the cleartext Wi-Fi password. Treat the
  generated `.bat` like a credential file.
