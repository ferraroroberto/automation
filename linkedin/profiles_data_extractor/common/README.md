# Common Components

Shared utilities and dashboard for LinkedIn profiles data extraction.

## Files

- `dashboard.py` - Streamlit dashboard for data visualization
- `excel_format_manager.py` - Excel formatting and hyperlink utilities
- `linkedin_profiles_data.json` - Configuration file with extraction settings
- `excel_format_spec.json` - Excel formatting specifications

## Usage

### Dashboard
```bash
dashboard.bat
```
Launches Streamlit dashboard to visualize extracted LinkedIn data.

### Test Excel Formatting
```bash
test_excel_format.bat
```
Tests Excel formatting and hyperlink functionality.

## Configuration

Edit `linkedin_profiles_data.json` to configure:
- Output paths
- Excel file locations
- Extraction settings
- Tab management parameters
